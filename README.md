ML Practice
My first Machine Learning project using KNN algorithm.

Project Structure
practice s6.py - Main script with KNN classifier

How to Run
python "practice s6.py"

Requirements
Python 3.12+
scikit-learn
numpy

Install dependencies:
pip install scikit-learn

What it does
This project uses K-Nearest Neighbors (KNN) algorithm to classify
people as young (0) or adult (1) based on their age.
